Baseball Lab S&C V5.3 · 최종 수정: 2026년 5월

1. Baseball Lab S&C란

Baseball Lab S&C는 야구 선수·동호인과 지도자, 보호자가 훈련 데이터를 함께 기록·관리할 수 있도록 돕는 웹 기반 훈련 관리 도구입니다. 별도의 회원가입이나 서버 전송 없이, 사용자의 브라우저 안에서 동작합니다.

2. 주요 기능

  • 선수 등록: 이름·나이·구력 등 기본 정보를 입력하여 선수를 등록합니다.
  • 8종목 정밀평가: 가동성·근력·파워·밸런스 등 8개 영역을 점검합니다.
  • 7일 스케줄: 평가 결과에 기반한 7일 훈련 스케줄과 운동별 가이드를 제공합니다.
  • 워크로드 / ACWR: 일별 RPE·투구/스윙 수 기록을 바탕으로 워크로드와 급성·만성 비율을 추적합니다.
  • 백업 / 복원: 모든 선수 데이터를 JSON으로 백업하고 동일 형식으로 복원합니다.

3. 사용 대상

  • 유소년·학생 선수
  • 사회인·취미 야구인
  • 아마추어 투수·타자
  • 코치·지도자
  • 보호자

4. 안전 고지 요약

Baseball Lab S&C는 의료 진단·치료·처방 도구가 아닙니다. 앱이 제공하는 워크로드, ACWR, RPE 등의 수치는 참고 지표이며, 최종 훈련 판단은 코치와 선수 본인의 책임입니다. 통증·부상이 의심될 때에는 즉시 훈련을 중단하고 전문가에게 확인하세요.

5. 더 알아보기

  • 워크로드와 ACWR 이해하기 — 일별 부하 계산과 ACWR 해석.
  • 등판 후 회복 기록 가이드 — 컨디션·통증·수면 기록의 의미.
  • 8종목 정밀평가 활용법 — 점수의 한계와 재평가 주기.
