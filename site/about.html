서비스 소개

Baseball Lab S&C V5.3 · 최종 수정: 2026년 6월

01Baseball Lab S&C란

Baseball Lab S&C는 야구 선수·동호인과 지도자, 보호자가 훈련 데이터를 함께 기록·관리할 수 있도록 돕는 웹 기반 훈련 관리 도구입니다. 별도의 회원가입이나 서버 전송 없이, 사용자의 브라우저 안에서 동작합니다.

02이 서비스의 차별점

Baseball Lab S&C는 야구 훈련 기록·회복·워크로드·정밀평가를 따로 떼어 보지 않고 하나의 흐름으로 연결해 보는 구조를 우선합니다. 같은 RPE 값도 워크로드·ACWR·회복 기록과 함께 놓으면 의미가 달라지므로, 한 페이지 안에서 강도(RPE), 양(투구·스윙 수), 누적 부하(ACWR), 회복 신호(컨디션·통증·피로·수면), 동작 기반(정밀평가 8종)을 같은 시간 축 위에 모아 두는 것을 기본으로 두고 있습니다.

또 다른 차별점은 가입과 서버 전송 없이 사용자의 브라우저 안에서만 동작한다는 점입니다. 개인 데이터는 사용자 기기 밖으로 나가지 않고, 사용자가 직접 백업 파일을 만들고 옮기는 방식을 택해 데이터 통제권이 사용자에게 남도록 설계했습니다. 그리고 어떤 화면에서도 자동으로 부상 위험·훈련 가·부를 판정하지 않습니다. 수치는 코치·선수·보호자가 함께 들여다보며 다음 한 주를 의논하는 자료로 쓰는 것을 전제로 합니다.

03주요 기능

  • 선수 등록: 이름·나이·구력 등 기본 정보를 입력하여 선수를 등록합니다.
  • 8종목 정밀평가: 가동성·근력·파워·밸런스 등 8개 영역을 점검합니다.
  • 7일 스케줄: 평가 결과에 기반한 7일 훈련 스케줄과 운동별 가이드를 제공합니다.
  • 워크로드 / ACWR: 일별 RPE·투구/스윙 수 기록을 바탕으로 워크로드와 급성·만성 비율을 추적합니다.
  • 백업 / 복원: 모든 선수 데이터를 JSON으로 백업하고 동일 형식으로 복원합니다.

04사용 대상

  • 유소년·학생 선수
  • 사회인·취미 야구인
  • 아마추어 투수·타자
  • 코치·지도자
  • 보호자

05안전 고지 요약

Baseball Lab S&C는 의료 진단·치료·처방 도구가 아닙니다. 앱이 제공하는 워크로드, ACWR, RPE 등의 수치는 참고 지표이며, 최종 훈련 판단은 코치와 선수 본인의 책임입니다. 통증·부상이 의심될 때에는 즉시 훈련을 중단하고 전문가에게 확인하세요.

06자주 묻는 질문

Q. 데이터는 어디에 저장되나요?

브라우저(localStorage)에만 저장되고 서버로 전송되지 않습니다. 기기 변경·브라우저 정리 시 사라질 수 있어 정기 백업을 권장합니다.

Q. 회원가입이나 로그인이 필요한가요?

필요하지 않습니다. 설치·가입 없이 브라우저에서 바로 사용합니다.

Q. 비용이 드나요?

별도 비용 없이 사용할 수 있습니다.

Q. 의료용 도구인가요?

아니요. 진단·치료·처방을 위한 도구가 아니며, 워크로드·ACWR·RPE 등은 참고 지표입니다. 통증이 의심되면 전문가에게 확인하세요.

Q. 여러 기기에서 같은 데이터를 볼 수 있나요?

데이터는 기기별 브라우저에 저장되어 자동으로 동기화되지 않습니다. 백업 파일을 내려받아 다른 기기에서 복원하면 옮길 수 있습니다.

07데이터 보관 방식과 백업 책임

본 서비스는 입력된 모든 선수·훈련·평가 기록을 사용자의 브라우저 안 localStorage 영역에 저장합니다. 별도의 서버 데이터베이스로 전송하지 않으며, 같은 도메인의 다른 브라우저나 다른 기기에서는 동일한 데이터를 자동으로 볼 수 없습니다. 이 구조의 장점은 데이터가 사용자의 기기 안에만 머문다는 점이고, 반대로 책임도 사용자에게 더 많이 남는다는 의미입니다.

  • 사라질 수 있는 상황 — 브라우저 데이터 정리, 시크릿/프라이빗 모드 종료, 기기 초기화, 브라우저 자체 재설치 등이 발생하면 localStorage 데이터가 함께 사라질 수 있습니다.
  • 권장 백업 방식 — 앱 내 백업 다운로드 기능으로 JSON 파일을 만들고, 클라우드 저장소나 외장 저장 매체에 보관합니다. 기기를 바꿀 때는 새 기기에서 같은 JSON 파일을 복원하면 데이터가 이어집니다.
  • 백업 주기 — 정해진 의무는 없지만, 새 선수를 등록하거나 정밀평가·중요한 등판 기록을 추가한 직후에 백업을 한 번 더 만들어 두는 편이 안전합니다.
  • 여러 기기 사용 — 자동 동기화가 없으므로 같은 데이터를 두 기기에서 보려면 한쪽에서 백업 → 다른 쪽에서 복원하는 흐름을 따릅니다.

08광고·개인정보·문의 신뢰 신호

서비스를 사용하면서 알아 두면 좋은 신뢰 신호를 한 문장씩 정리합니다.

  • 광고 — 본 서비스는 Google AdSense 광고를 통해 운영비를 일부 충당합니다. 광고는 가이드 문서를 중심으로 노출되며, 선수 등록·평가 저장·워크로드/RPE 입력·백업/복원처럼 앱 조작에 영향을 줄 수 있는 영역 주변은 가급적 피하는 방향으로 운영합니다. 광고와 관련된 자세한 정책은 이용약관 및 안전 고지에서 다룹니다.
  • 개인정보 처리 — 본 서비스는 가입 정보를 받지 않으며, 입력된 훈련 데이터를 서버로 수집하지 않습니다. 광고 표시와 사이트 분석을 위해 외부 서비스(Google)에 일부 정보가 전달될 수 있으며, 자세한 처리 범위는 개인정보처리방침에서 확인할 수 있습니다.
  • 문의·지원 — 앱 오류, 사용 방법, 데이터 백업/복원 관련 문의는 문의/지원 페이지의 안내를 따라 보내 주세요. 의료 판단·진단·처방·성과 보장에 관한 문의는 응대 범위가 아니므로 전문가 확인을 권장합니다.
  • 안전 고지 — 본 서비스의 어떤 화면, 어떤 가이드도 의료 진단·치료·처방을 대신하지 않습니다. 통증·부상이 의심될 때에는 화면의 수치보다 전문가의 직접 평가가 우선입니다.

09더 알아보기

  • 공개 가이드 모음 — RPE, ACWR, 회복 기록, 정밀평가, 훈련 프로그램 자료를 한곳에서 확인.
  • RPE 입력 가이드 — 0~10 입력 기준과 흔한 입력 실수.
  • ACWR 안전한 해석 가이드 — 부하 흐름·통증·회복 신호를 함께 보는 방법.
  • 워크로드와 ACWR 이해하기 — 일별 부하 계산과 ACWR 해석.
  • 등판 후 회복 기록 가이드 — 컨디션·통증·수면 기록의 의미.
  • 8종목 정밀평가 활용법 — 점수의 한계와 재평가 주기.
  • 야구 S&C 훈련 프로그램 구성 가이드 — 훈련 축 비중과 앱 추천을 읽는 법.
  • 준비운동·어깨 가동성 가이드 — 훈련 전 움직임 확인과 통증 없는 범위 참고.
  • 수비·주루·민첩성 가이드 — 주루 준비, 방향 전환, 수비 움직임 확인 참고.
