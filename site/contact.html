01문의 전 확인사항

오류 또는 데이터 이상이 의심될 때, 문의 전에 아래 사항을 먼저 확인해 주세요.

  • 백업: 데이터 관리 화면에서 백업 다운로드를 1회 실행했는지 확인합니다. 문의 과정에서 데이터가 변경될 가능성이 있으므로 백업이 안전 장치가 됩니다.
  • localStorage 의존: 모든 데이터는 사용자 기기의 브라우저 localStorage에만 저장됩니다. 브라우저를 초기화하거나 시크릿 모드를 사용하면 데이터가 사라질 수 있습니다.
  • 브라우저 환경: Chrome 최신 버전을 권장합니다. 브라우저 확장 프로그램이 동작에 영향을 줄 수 있으므로 시크릿 창에서 재현되는지 확인하면 도움이 됩니다.

02문의 가능한 항목

  • 앱 동작 오류: 사용 중 발생한 오류, 예기치 못한 동작, 화면 깨짐 등.
  • 기능 개선·제안: 기존 기능 개선안 또는 신규 기능 제안.
  • 백업/복원 문의: 백업 다운로드, 복원 실패, 백업 파일 구조 등 데이터 입출력 관련 문의.
  • 개인정보 문의: 처리 방식, 보관·삭제 절차, 미성년자 데이터 입력 관련 문의.
  • 정정·삭제 요청: 본인 또는 보호자가 자신의 데이터 정정·삭제를 직접 수행하기 어려운 경우의 안내 요청. (앱 내 삭제는 사용자가 직접 수행할 수 있습니다.)

04응대 범위

운영자는 앱 동작 및 데이터 처리에 관한 문의에 대해 합리적인 범위 내에서 답변을 제공합니다. 의료적 판단, 부상 진단, 훈련 처방, 성과 보장 관련 문의에는 답변하지 않으며, 해당 사안은 의사·물리치료사·코치 등 전문가에게 직접 문의해야 합니다.

05자주 묻는 질문

Q. 데이터를 백업하려면 어떻게 하나요?

앱 화면의 "백업 다운로드"로 기록을 JSON 파일로 저장할 수 있습니다.

Q. 기기를 바꾸면 데이터가 자동으로 옮겨지나요?

자동으로 옮겨지지 않습니다. 기존 기기에서 백업 파일을 내려받아 새 기기에서 "복원"하세요.

Q. 데이터가 사라졌어요.

localStorage 특성상 브라우저 기록 정리·시크릿(비공개) 모드 종료 시 사라질 수 있습니다. 평소 정기 백업을 권장합니다.

Q. 개인정보·광고 관련 문의는 어디로 하나요?

같은 운영자 이메일로 문의하시면 됩니다.

Q. 어떤 문의에 답변하나요?

앱 오류·기능·데이터 관련 문의에 응대합니다. 의료적 판단·진단·처방·성과 보장과 관련된 문의에는 답변하지 않으며, 전문가에게 확인하시길 권장합니다.

문의 응답 시점은 운영자 사정에 따라 지연될 수 있습니다. 긴급한 신체 이상은 본 페이지가 아닌 의료 전문가에게 즉시 확인하시기 바랍니다.
