# 근거문서 사용 안내

## 1. 역할
- 근거/문서 에이전트: 출처 조사, 초안 작성, 후속 정리.
- 근거 검토 에이전트 또는 총괄 Codex: 출처 신뢰도, 저작권/표현 리스크, 앱 반영 가능성 검토.
- 총괄 Codex: 근거문서 검토 결과를 바탕으로 코드 반영 승인 여부만 결정.

## 2. 문서 구분
- 현재 판단 기준 문서: `docs/evidence/evidence-research.md`
- 과거 기록, 보류 판단, 최신 기준으로 대체된 기록: `docs/evidence/evidence-archive.md`

## 3. 사용 규칙
- 현재 앱 반영 판단은 `docs/evidence/evidence-research.md`의 최신 활성 섹션만 기준으로 삼는다.
- 과거 조사, 보류 판단, 출처 오류 보정 기록, 비활성 기록은 `docs/evidence/evidence-archive.md`에서만 확인한다.
- 근거문서만으로 `site/*`를 수정하지 않는다.
- 코드 반영 전에는 반드시 총괄 Codex 승인이 필요하다.
- 앱 반영 가능성은 `코드 반영 가능`, `설계 후 반영 가능`, `보류` 3단계만 사용한다.

## 6. 출처 기준
- 공식 기관, 학회, peer-reviewed 논문, 교재, 전문 단체 자료를 우선한다.
- 블로그, 광고, 일반 유튜브는 단독 근거로 쓰지 않는다.
- 링크와 DOI/PMID/ISBN/발행정보를 가능한 범위에서 함께 남긴다.
- 유료 원문 표·그림·장문 인용은 남기지 않고 요약만 기록한다.

## 7. 표현 기준
- `치료`, `처방`, `진단`, `성과 향상 보장`, `부상 예방 보장`, `최적`, `자동 위험 판정`, `부상 예측` 같은 표현은 사용자 노출 후보로 두지 않는다.
- 의료·회복·워크로드 관련 문구는 `참고`, `확인`, `조정 고려`, `도움이 될 수 있음`, `전문가 상담 권장` 수준으로 유지한다.

## 8. 총괄 Codex로 넘기는 조건
- 출처 링크와 적용 대상이 구분되어 있다.
- 저작권 리스크가 있는 장문 인용, 표, 그림 재게시가 없다.
- 사용자 노출 후보 문구가 안전한 표현으로 정리되어 있다.
- 총괄 Codex 판단 질문이 3개 이하로 정리되어 있다.
