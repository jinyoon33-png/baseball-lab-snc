# Baseball Lab S&C 근거 조사 문서

## 1. 사용 목적
- 이 문서는 훈련 프로그램, 운동 선택, 워크로드·회복 판단, 사용자 유형별 조정 근거를 모으는 조사 문서다.
- Claude 조사 담당은 이 파일에 근거 보고서를 추가하고, 현재 Codex는 출처·표현·앱 반영 가능성을 최종 검토한다.
- 이 문서는 구현 지시서가 아니다. 앱 반영은 별도 `docs/workflow/work-plan.md` 티켓으로만 진행한다.

## 2. 작성 규칙
- 모든 핵심 주장에는 출처 링크를 붙인다.
- 공식 기관, 학회, 논문, 교재, 전문 단체 자료를 우선한다.
- 블로그, 일반 유튜브, 광고성 콘텐츠는 보조 근거로만 사용한다.
- `치료`, `처방`, `진단`, `보장`, `성과 향상 보장`, `부상 예방 보장`, `최적` 같은 단정 표현은 사용자 노출 문구로 제안하지 않는다.
- 의료·재활·부상 관련 내용은 “관리”, “참고”, “확인”, “조정”, “전문가 상담 권장” 수준으로 완화한다.

## 3. 검토 상태 표기
- `미검토`: Claude가 작성했지만 Codex 검토 전.
- `검토 완료`: 출처와 표현을 Codex가 확인함.
- `보류`: 근거가 약하거나 앱 반영 리스크가 큼.
- `폐기`: 출처 부적합, 표현 위험, 앱 목적과 불일치.

### 2026-05-19 — 훈련 프로그램·사용자 유형·위치별 차별화 근거
- 상태: `검토 완료`

- 요약 결론:
  - 사용자별 차이: 청소년(생물학적 성숙도 필수 반영), 성인(강도 증가), 취미(안전·접근성 우선) [근거: NSCA peer-reviewed]
  - 투수 vs 타자: 하체·회전 파워 공통, 투수는 어깨·흉추·고관절 안정성·가동성 개발에 차별화 필요 [근거: Driveline 실무, NSCA periodization]

  - 운동 선택 기준: intensityTier, skillTier, movementPattern, equipmentLevel 설계 타당 [근거: 복합 근거]

#### Codex 검토 필요 질문
1. **생물학적 성숙도 입력 필요성**: 청소년 프로그램 정확도 향상을 위해 생물학적 성숙도 관련 입력이 실제로 필요한가? 민감정보와 입력 복잡도 대비 효과는 충분한가?
