# 프로젝트 운영 기준 공간

## 주 파일
- 작업 공간 맵: `docs/project/workspace-map.md`
- 이슈 분류 기준: `docs/project/ticket-conventions.md`
- 공통 검증 명령: `docs/security/verify-common.md`
- 담당별 시작 프롬프트: `docs/project/role-prompts.md`

## 목적
- 담당별 책임 범위와 파일 경계를 고정한다.
- 반복되는 검증 기준을 한 곳에서 참조하게 한다.
- 워크플랜과 근거문서가 서로 섞이지 않도록 운영 기준을 유지한다.

## 유지 원칙
- 공통 기준을 바꾸면 `docs/project/workspace-map.md`도 함께 확인한다.
- 활성 티켓에 운영 원칙을 반복해서 길게 붙이지 않는다.
- 새 담당을 추가할 때는 먼저 `docs/project/workspace-map.md`에 역할과 금지 범위를 기록한다.
