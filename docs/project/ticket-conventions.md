# Ticket Conventions

## Severity
- BLOCKER: 코드/데이터 손상, 무수정 대상 변경, 저장 schema/복원 차단 위험, 주요 기능 회귀, 완료 결과 위조.
- MAJOR: 설계와 구현 불일치, 사용자에게 잘못된 의미 전달, 중요 검증 누락, 브라우저 미수행을 완료로 과장.
- MINOR: 문구 일부 부정확, 결과 섹션 누락, line 번호 drift, 검증 기록 일부 부족.
- NIT: 표기, 띄어쓰기, 섹션 번호, 사소한 문서 일관성.

## Roles
- 총괄 Codex: 티켓 선정, 작업 지시, 워크플랜 작성, 최종 검토, 사용자 보고를 담당한다.
- 코드 구현 에이전트: 활성 티켓의 허용 파일만 수정하고 완료 보고는 변경 파일/요약/검증/리스크로 제한한다.
- 보안/QA 에이전트: 보안/정적 점검 담당. 읽기와 보고만 수행하고 파일 수정 금지.
- 브라우저 QA 에이전트: 사용자 흐름, 반응형, 콘솔 오류, overflow, 다크모드/라이트모드를 확인한다. 파일 수정 금지.
- 근거/문서 에이전트: 근거 조사 작성 담당. `docs/evidence/*`만 수정하고 코드/워크플랜은 수정 금지.
- 릴리즈 점검 에이전트: 배포 전후 git/도메인/정책 파일/AdSense 관련 상태를 읽기 전용으로 확인한다.
- 모든 하위 에이전트: 다음 티켓을 임의로 선택하지 않고 최종 완료 판단을 하지 않는다.
