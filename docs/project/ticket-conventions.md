# Ticket Conventions

## Severity
- BLOCKER: 코드/데이터 손상, 무수정 대상 변경, 저장 schema/복원 차단 위험, 주요 기능 회귀, 완료 결과 위조.
- MAJOR: 설계와 구현 불일치, 사용자에게 잘못된 의미 전달, 중요 검증 누락, 브라우저 미수행을 완료로 과장.
- MINOR: 문구 일부 부정확, 결과 섹션 누락, line 번호 drift, 검증 기록 일부 부족.
- NIT: 표기, 띄어쓰기, 섹션 번호, 사소한 문서 일관성.

## Roles
- Claude Code: 구현 담당. 활성 티켓의 허용 파일만 수정하고 완료 보고는 변경 파일/요약/검증/리스크로 제한.
- 보안/QA Claude Code: 보안/정적 점검 담당. 읽기와 보고만 수행하고 파일 수정 금지.
- 근거문서 Claude: 근거 조사 작성 담당. `docs/evidence/*`만 수정하고 코드/워크플랜은 수정 금지.
- 근거문서 검토 Codex: 근거 검토 팀장. 근거문서의 출처/표현/반영 가능성을 검토하고 총괄 질문은 최대 3개로 제한.
- Current Codex: 총괄 PM/아키텍트/최종 정밀검토 담당. 기본적으로 `docs/workflow/*`와 `docs/project/*` 운영 문서만 수정.
